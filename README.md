# Liên Việt Door

Trang Tổng quan vận hành nội bộ. Giai đoạn này có Khách hàng, Công trình và Báo giá.

```bash
npm install
npm run dev
```

Mở `http://localhost:3000`, chọn tài khoản trên màn đăng nhập.

`DASHBOARD_DATA_SOURCE=demo` bật dữ liệu minh họa, có nhãn trên trang. Không đặt biến này thì trang không dùng số giả. `SHOW_PLANNED_MODULES=true` hiện mục chưa làm ở dạng tắt, chỉ với người có quyền tương ứng.
